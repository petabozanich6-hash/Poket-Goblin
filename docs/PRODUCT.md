# Product — Pocket Goblin

**Tagline:** Your brain has enough tabs open. Let the goblin handle it.

## Principle

THE USER PROVIDES THE THOUGHT.  
THE GOBLIN HANDLES THE ORGANISATION.

## Built-in systems (roadmap)

| Area                                                                               | Sprint |
| ---------------------------------------------------------------------------------- | ------ |
| Den, capture, tasks, categories, capacity plan, auth, D1                           | 1      |
| Calendar, reminders, recurring, notes, shopping, search                            | 2      |
| Intelligence engine (AI + rule fallback), Ask, breakdown                           | 3      |
| Document vault, inbox, voice, OAuth foundations                                    | 4      |
| Daily briefing, overwhelm mode, Rescue My Day, tiny steps, nudges, personalisation | 5      |

## Magical companion behaviours (Sprint 5)

- **Daily briefing** — what matters today, from real shelves only
- **I’m overwhelmed** — one calm focus + tiny start
- **Help me start** — smallest practical first step
- **Rescue my day** — revise today’s focus without moving appointments or due dates
- **Gentle nudges** — in-app, preference-controlled, quiet hours respected
- **Optional quests** — milestones only; can be disabled

## Tone

Whimsical, cosy, storybook goblin companion — modern and calm, never clinical or childish.
