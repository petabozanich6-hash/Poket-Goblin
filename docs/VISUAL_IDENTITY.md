# Visual identity

Official Pocket Goblin art direction lives in the fantasy asset library:

**[docs/assets/pocket-goblin-fantasy-asset-library.jpg](./assets/pocket-goblin-fantasy-asset-library.jpg)**

That sheet is the source of truth for character design, expressions, empty states, navigation icons, category icons, capacity-mode metaphors, and den environments.

## Rules for product work

1. Preserve the goblin’s green skin, large pointed ears, brown aviator goggles, leather clothing, and warm painterly storybook appearance.
2. Keep a consistent woodland-fantasy palette (`#4A5D23`, `#8B5A2B`, `#F5E6BE`, `#D4A373`).
3. Do not recreate the character with emoji, CSS shapes, or generic AI-generated goblins.
4. Do not crop individual assets from these reference sheets for production. Dedicated assets will replace existing imagery when ready.

Cursor agents also load `.cursor/rules/visual-identity.mdc` on every session.
